## Five questions

**1. Purpose and original intent.** §5 exists because the strategy "define[s] a concrete instance" via a declared parameter vector, presented not as defaults but as *baselines plus exploration ranges* (`docs/DVT_..._v4_1.md:967`, `:975-1064`), with §5.2 explicitly enumerating the *relations* between parameters that make individual ranges meaningless in isolation (`:1066-1080`). §6 is the intended response to underperformance: alternatives applied "iteratively in order of diagnostic priority", each with a named failure mode, a **diagnostic trigger**, a cost, and a prerequisite (`:1086`). The philosophical requirement layered on top is that the risk model be a self-contained object and the return view an additive, removable term (`docs/strategy_philosophy.md:154-168`).

**2. What a state-of-the-art version looks like.** Not better hyperparameter search — fewer live degrees of freedom and a complete, immutable record of the ones that exist. Concretely: (i) one manifest per run storing every *consumed* value including derived ones (`N_eff`, `AU_max_stat`, `n_signal`, effective ENB, the shrinker actually executed, package versions); (ii) frozen exploration ranges declared before the holdout is touched (Bergstra & Bengio 2012 for the search side; Bailey & López de Prado 2014 "Deflated Sharpe", Harvey, Liu & Zhu 2016, White 2000 / Hansen 2005 SPA for the multiple-comparison side); (iii) selection statistics corrected for the number of configurations tried; (iv) objective variants as an enumerated type, not as several independent booleans; (v) derived quantities computed, never set. Technically the unit is already near-SOTA in its *choices* — Barra USE4 standardization (Menchero, Orr & Wang 2011), DGJ (2018) spiked shrinkage applied standalone, LW 2020 nonlinear, Kish (1965) effective sample size, Meucci (2009)/Roncalli (2013 Ch. 7) for ENB and budgeted entropy. The gap is governance, not econometrics.

**3. What prevents it — and which obstacles are only apparent.** Real obstacles: four independent config layers (`src/config.py` defaults; notebook Section 2b; `scripts/run_diagnostic.py:83-124` PROFILES; per-call kwargs), no precedence rule, and artifacts that omit the governing fields — `results/diagnostic/config.json` contains **no** `entropy_budget_mode`, `normalize_entropy_gradient`, `frontier_*` or `oos_*` key, i.e. the only real-data run does not record which entropy objective it solved. Two knobs are inert (`EIGENVALUE_POWER`, `sigma_z_eigenvalue_pct` under the default shrinker), one is silently environment-dependent (covShrinkage fallback, `covariance.py:277,446-447`). *Apparent* obstacles: (a) the K = 200 / 75 / 50 / 100 spread is largely immaterial — effective capacity is `min(K, 2·AU_max_stat)` decided from data (`pipeline.py:307-314`), so K is a ceiling nobody reaches; (b) the `w_bar` = 3% / 1.5% conflict is immaterial **because** the recorded run has `phi = 0.0` (`results/diagnostic/config.json`), and `w_bar` only enters through the φ-penalty — two of the three concentration knobs are dead simultaneously; (c) the λ = 1.0 vs 252.0 conflict is only *partly* apparent: absolute scale is irrelevant to `argmax` while no unscaled penalty acts, but φ, κ₁, κ₂ and any ENB target are unscaled, so the doc's claim that "only ratio α/λ matters" (`:1051`) fails exactly when the portfolio is the one actually solved.

**4. Real vs self-imposed constraints.** Real: the Σ_z estimation bound `AU_max_stat ≈ 85` for 30y daily at r_min = 2 (`:1072`; arithmetic check: ⌊√(2·7560/2)⌋ = 86 ≈ 85); the non-scale-invariance of a penalized objective; window overlap ⇒ effective samples ≈ T_hist/T, not T_hist−T+1 (`:1076`); 16 GB compute; equity cross-sectional R² of 1–3% (`:1163`). Self-imposed: K = 75; `entropy_idio_weight = 0.20` (which means the shipped objective is *not* the §7 equal-contribution entropy); φ = 0 (deleting Principle 8's intra-factor half, `philosophy.md:136-150`); the four competing α-selection mechanisms; `n_stocks = 4500` with no cap/ADV in `config.py` at all (those live in function signatures: `universe.py:19`, `data_loader.py:201`); holdout = 3y (one draw) versus `_diagnostic.holdout_fraction = 0.2` ≈ 6.3y actually used.

**5. Remove / merge / move.** Remove: `EIGENVALUE_POWER` (dead), `sigma_z_eigenvalue_pct` from the default path (inert under non-truncation shrinkers, `covariance.py:220-221`), `beta_fixed` from any mode where it is a silent no-op, and the three redundant α-selection mechanisms — keep exactly one (adaptive ENB target), demote grids to *evaluation* grids. Merge: `entropy_budget_mode` + `entropy_idio_weight` + `normalize_entropy_gradient` into one enumerated `objective` (pure FRP / tilted / two-layer), so the report always names the objective solved. Move: universe-defining parameters (cap entry/exit, ADV, min history) out of function signatures into the manifest; the notebook constants out of the notebook into the manifest. None of these removals costs a strength — each target is inert, redundant, or uncalibrated.

## Core strengths to preserve

1. **The derived capacity bound, not the chosen K.** `AU_max_stat = ⌊√(2N_eff/r_min)⌋` plus Kish correction is the only mechanism in the system that answers "how many risk factors exist" without a human choice. A redesign should keep it as the *single* entry point for factor count, and delete the decorative K range around it.
2. **Phase 0 + INV-012 + the shared α-selection rule.** The comparison is fair at the level of constraints *and* at the level of the diversification objective, including for PCA-FRP. Any redesign that redefines the objective must re-instantiate the same rule on both sides, or the kill criterion becomes unfalsifiable.
3. **The pre-registered kill criterion** (Iteration 6, `philosophy.md:183-185`): paired test on H̄_OOS, p < 0.05, "complexity must earn its place". Keep verbatim, including the willingness to abandon the VAE.
4. **μ = 0 by default with a single additive return term.** This is the cleanest architectural boundary present and it is physically enforced (separate module, one term, default off). It is what makes the risk model validatable on its own.
5. **Standalone-shrinker discipline** — "chaining LW then DGJ would inflate the bulk noise estimate and misclassify signal as noise" (`covariance.py:204-207`). This is correct and is exactly the kind of subtlety a rewrite silently breaks.
6. **Overlap-aware effective sample size** and the accompanying refusal to count 7,500 overlapping windows as 7,500 independent observations.
7. **Fail-fast invariant validation** (T/F match, w_min < w̄ < w_max, vt-clamp ordering, curriculum sum ≤ 1, fold budget). Keep the invariant *set* even if the container changes.
8. **The shape of Iterations 1 and 2**: single downstream estimator swapped, no retraining, evaluated on existing VAE outputs. That "change one downstream object, re-evaluate on frozen upstream artifacts" pattern is the cheapest legitimate experiment design available and should be the template for everything after the redesign — including for the manifest problem in U15-ADV-12.

## Verdict

The *theory* of this unit is close to right and in places better than the specification: a derived statistical capacity bound that actually reproduces the document's number, a correct identifiability argument for Mode P, correct treatment of window overlap, a fair benchmark harness that shares not only constraints but the α-selection rule, a genuinely clean risk/return separation, and a roadmap with pre-registered triggers and a stated kill criterion. Its *practice* is where it fails: the parameter layer has four sources of truth, no manifest, two dead knobs, one environment-dependent estimator, one unrecorded objective switch, an uncalibrated return-view scale, and a claim ("only α/λ matters") that is false for the portfolio that is actually solved. The single most damaging item is U15-ADV-12 — the only real-data run's parameter vector cannot be regenerated from the repository — because it makes every other unit's trigger-based conclusion conditional on an unknown instance. None of these are arguments for adding machinery; they are arguments for deleting inert knobs, collapsing the four α mechanisms into one, moving the notebook and universe filters into a recorded manifest, and keeping the six strengths above untouched.

Score: 6/10
